## 自动化行为覆盖

- 图表与 Slider 局部单元测试共 80 项通过：正负值、零、空与无效状态、全部类别、极端有限数值、统一格式化、本地化、实例名称及完整表格。
- 图表浏览器测试共 15 项通过：鼠标命中与提示悬停、Esc 同项抑制、触摸移动和取消、触摸开关、全部类别可达、Tab 退出、快照变化清理、焦点衔接、多图表浮层栈、Dialog 关闭顺序及卸载清理。
- 图表 SSR 定向测试通过，服务端渲染不依赖浏览器全局对象。
- 独立 Playwright 文档站验证覆盖滚动后保留活动项、390 × 844 窄屏提示边界、减少动态效果、强制颜色、真实触摸事件与 Dialog 两次 Esc；页面运行时异常为零。
- UI 与文档站类型检查、局部 ESLint、契约检查、双语镜像与文档检查通过；UI 构建、注册表构建与 93 个注册项验证通过，注册表增量与全量构建输出一致。
- 消费者矩阵 U1、C1 通过，覆盖 npm 包根入口与子路径、严格类型、CLI 源码安装、公开索引、更新保护和生产构建。Windows 执行环境须能在 PATH 中直接启动 `pnpm.exe`。

自动化触摸事件不等同于触摸屏幕阅读器实测；辅助技术结论以上表的使用者反馈为准。

## 视觉与定位

验收使用 Windows 11、Chromium 148.0.7778.96。三类图形在 classic、pastel、mono 亮暗主题下生成 18 张截图，并检查桌面与窄屏表现。活动项使用轮廓或下划线表达；柱体排线具有独立底色。强制颜色模式使用系统色保留图形、轴线及文字，关闭手绘滤镜。提示复用浮层定位并挂载到当前 Dialog 或文档 body，以避开普通父容器裁切。
