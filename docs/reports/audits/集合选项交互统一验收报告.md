关联方案：[集合选项柠檬黄交互统一改造方案](../../archive/2026/ui/集合选项柠檬黄交互统一改造方案.md)

## 实施范围

Select、Command / Combobox、Cascader、TreeSelect、TreeView、Transfer、DropdownMenu 接入共享集合行样式。Classic 明暗模式使用柠檬黄与黑色前景，其他预设复用各自强调色对；主题编辑器、UI 样式与 CLI 模板同步新增色对。

各组件保留业务提交策略。选择标记固定占位，当前项与可见焦点分别表达；TreeSelect 的相邻导航与 Home/End 共用禁用筛选。Command 的私有输入模式只影响虚拟焦点呈现。危险菜单项通过 `data-tone="danger"` 表达语义。

视觉系统、CVA 指南、主题定制说明、八类集合组件的中英文页面以及相关 API 数据同步交付。

## 状态转换回归

- Cascader 的多选可见焦点使用完整选项路径，选项重排后与真实焦点保持一致；覆盖离焦、移除重开、跨列同值及字符串与数字值。
- Command 搜索框通过 Home、End 与 Shift+ArrowDown 从指针模式进行实际导航时，唯一虚拟焦点标记与高亮项、`aria-activedescendant` 一致，导航保持搜索框焦点且不提交选值。
- TreeSelect 先通过真实 Tab 与方向键进入树并跳过禁用节点，再将现有节点全部禁用或替换为禁用节点；开启搜索时回到搜索框，关闭搜索时回到对应触发器。同时禁用节点并隐藏搜索框时，触发器持有焦点且弹层保持打开；测试同时核验原节点继续渲染。初始全禁用的搜索框焦点独立验收。
- C1 为每个更新目标建立基线差异，并在实际消费项目中确认共享私有模块为旧内容、新增模块尚未落盘，再执行更新并精确比对候选投影内容。共享模块路径与 import 别名由 CLI 的 `ProjectContext` 解析；Button 的本地修改持续保留，候选基线标记从更新结果中移除。
