## 三、并行审查与缺陷修复（Subagent Parallel Review）

经过 4 个专用 Subagent（Kanban & Selection Reviewer、DataTable Pipeline Reviewer、Audio Runtime Reviewer、Contract & Standards Reviewer）对 4 个工作包的代码实现、架构分层、规范合规与单体验证进行全景审查，发现并修复了以下核心缺陷与工程阻断点：

### 3.1 阻断性缺陷与工程修复

1. **Registry 依赖提取与 Monorepo 分层自愈**：
   - 根因：`useDataTablePipeline.ts` 原落位于 `src/lib/data-table/`，导致 `src/lib` 底层基础设施依赖高层 `composite` 组合式函数，且 `ast-rewriter` 无法递归解析目录导入，导致 `packages/ui/registry-manifest.json` 漏失 DataTable 的 4 个 composable，Registry 构建直接熔断抛错。
   - 修复：将 `useDataTablePipeline.ts` 迁入 `packages/ui/src/components/data-table/useDataTablePipeline.ts`，归属 DataTable 组件内部编排；同时将 `lib/audio/` 与 `lib/kanban/` 按 monorepo 统一标准平铺至 `src/lib/*.ts`（`audio-adapter.ts`, `shared-audio-runtime.ts`, `kanban-operations.ts`, `kanban-types.ts`）。
   - 结果：`packages/ui/registry-manifest.json` 完整收录所有依赖，`pnpm --filter brutx-registry-vue validate` 与 `build-registry.ts` 100% 绿灯通过。

2. **SSR 安全与 DOM 作用域隔离（ESLint 门禁）**：
   - 根因：`KanbanBoard.vue` 内部裸调 `document.querySelector` 违反 SSR 安全规范并报 ESLint `no-restricted-globals`；跨组件看板实例查找存在选择器冲突与特殊 ID 字符崩溃风险。
   - 修复：引入 `@/lib/env` 的 `getDocument()`，根容器绑定 `boardRef` 优先做局部作用域查找；对 `cardId` 和 `columnId` 进行 `CSS.escape` 转义防守；列头补充 `tabindex="-1"` 防止回退聚焦时无障碍焦点丢失；修复 `kanban/types.ts` 的多层相对路径导入（对齐 `@/` 别名规范）。

3. **音频运行时 Closing 并发队列与 TTL 时效防抖**：
   - 根因：`SharedAudioRuntime` 在 `closingPromise` 存活期间直接向其 `finally` 回调链式追加 `handlePlaySound`，绕过了“单 lease 最新 1 条”时效覆盖，绕过了 300ms TTL 时效检查，且无法被 `cancelPending()` 取消；租约释放关闭时未重置 `this.resumingPromise`，导致新代次可能误继承旧 promise。
   - 修复：在 `closingPromise` 期间将发声请求正确压入 `this.pendingRequests`，`finally` 唤醒时执行代次更新并走标准 TTL 校验逻辑；租约释放时显式重置 `this.resumingPromise = null`；`WebAudioAdapter.close()` 补充注销 `statechange` 事件监听；遍历活跃句柄时使用 `Array.from(handles)` 防御迭代中 Set 变更。

4. **DataTable 增量过滤与 keySet 变更感知**：
   - 增强：`useDataTablePipeline` 比较新旧数据时加入 `newCount !== oldCount` 检查，拦截重复 ID 行数增减；在 `applyColumnFilterPatch` 中补充空数组 `[]` 与空日期范围 `{ start: null, end: null }` 的自动键清理，保持 filterState 干净。

5. **空值判定边界防守**：
   - 增强：`hasSelectionValue` 补充 `Number.isNaN(value)` 检查，防止数值型选择器异常解析产生的 `NaN` 被判定为有效值。
