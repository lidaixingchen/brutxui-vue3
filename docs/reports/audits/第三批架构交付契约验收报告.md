## 三、Button 成本与组织结论

保留 `Button effect="glitch"`。默认及关闭 effect 的路径满足资源契约，现有字节预算通过。资源管理使 Button 消费者 JS 增加 918 raw 字节、290 gzip 字节、275 Brotli 字节；本批收益来自资源启停正确性，计时样本不足以建立稳定的速度提升结论。

为隔离同期其他组件与主题变动，配对基线使用候选相同源码与构建配置，仅将 Button、useGlitchEffect、useReducedMotion 的运行时实现替换为起始提交版本；补充的 options 接口只参与类型生成。配对基线 tarball SHA-256 为 `27c0b0c572530b1d9bd1cf1d1772c6f8f820ae7ede6b7d58be01e9c4035b2a38`。起始提交原始 tarball 另保留为 `07596bf0e3a59d20e61312660ba7ab8f4f666045f6dd3aa45ff4f19dd0257736`。

采用 [cost profile](../../../packages/ui/perf/cost-profile.ts) 的 `r2-cost-baseline-v2`，相同 lock 模板、生产构建、可选 peers、浏览器和压缩参数，按候选—配对基线—候选顺序测量。每个浏览器场景预热两次，保留九次测量及离群样本。Tailwind 只扫描当前消费者源目录，场景的旧构建输出不参与下一场景扫描。

### 3.1 静态入口成本

下表单位均为字节，JS 包含消费者 Vue 等实际依赖。压缩值是逐文件压缩后的总和，不能直接与 size-limit 的口径混用。

| 场景 | 基线 JS raw / gzip / Brotli | 候选 JS raw / gzip / Brotli |
| --- | --- | --- |
| 空消费者 | 62945 / 24417 / 22195 | 62945 / 24417 / 22195 |
| 根入口 Button | 115906 / 43281 / 37993 | 116824 / 43571 / 38268 |
| 子路径 Button | 115906 / 43281 / 37993 | 116824 / 43571 / 38268 |
| Input | 113337 / 42268 / 37175 | 113337 / 42268 / 37175 |
| DataTable | 315878 / 103306 / 89732 | 316790 / 103607 / 90059 |
| GlitchText | 99813 / 36147 / 32409 | 100212 / 36237 / 32523 |
| 动态导入 Button 的首屏静态闭包 | 70298 / 27333 / 24796 | 70298 / 27333 / 24762 |

动态 Button 的递归动态闭包为候选 `119927 / 45412 / 40026`；DataTable 的递归动态闭包为 `339465 / 110335 / 96198`。该集合包含动态入口引用的静态共享 chunk，与首屏集合可能重叠，不能把两者直接相加。两次候选运行的全部字节指标一致。

聚合 CSS 在上述组件消费者中均为候选 `155673 / 22349 / 18183`，空消费者 CSS 为 `4044 / 1350 / 1132`。基础组件与特效共同消费聚合样式，本批没有按需 CSS 收益。生产页面验证 `inline-flex`、3px 实线边框、匹配的边框令牌与硬阴影，五个浏览器场景均通过。

现有 size-limit 实测：完整入口 142.87 kB / 上限 155 kB，Button 15.10 kB / 上限 22 kB，CSS 18.07 kB / 上限 20 kB；均为该工具含依赖、最小化与 Brotli 压缩的口径。

### 3.2 资源与时间

| 场景 | 基线 | 候选 |
| --- | --- | --- |
| effect=none | 1 个媒体监听，2 次文本读取，1 次 data-text 写入 | 特效媒体监听、定时器、文本读写均为 0 |
| effect=none + autoplay | 1 个 interval，1 个媒体监听 | 活跃 interval、timeout、媒体监听均为 0，文本读写为 0 |
| glitch + autoplay | 1 个 interval，1 个媒体监听 | 同一资源上限，卸载后为 0 |
| glitch + 减少动态效果 | interval 为 0，保留偏好监听 | interval 为 0，保留偏好监听，卸载后为 0 |
| glitch + KeepAlive 停用 | interval 释放，媒体监听仍为 1 | interval、timeout、媒体监听均释放，激活后按当前偏好恢复 |

浏览器统计中的测试等待 timeout 与组件资源通过生命周期断言区分；单测直接验证 effect 关闭后 `play()` 与 autoplay 都不能绕过开关。禁用、loading、effect 切换、文本变化、焦点、键盘、表单、asChild、ARIA、SSR 与水合均有回归覆盖。

默认 Button 挂载 p50/p95：配对基线 0.40/0.62 ms，候选第一次 0.40/0.70 ms，第二次 0.30/0.42 ms。样本存在重叠和计时粒度影响，时间暂作为报告项，未设置未经验证的阻断阈值。资源数量和字节预算继续作为确定性门禁。
