# 约定体系未纳入债清单

> 报告类型：既有债集中清单（约定体系修复方案范围外的组件代码修复项）
> 日期：2026-08-12
> 范围：C1-C8 组件代码修复不在[《约定体系修复方案》](../plans/约定体系修复方案.md)范围内（该方案只修约定体系自身：文档措辞 + 令牌补全 + 自动化兜底），本清单集中登记这些未纳入的既有债，作为后续收敛依据
> 来源：[约定与代码裁决审查报告](约定与代码裁决审查报告.md) 八条指控裁决

## 说明

清单内各项均以 `check:deprecated` 基线（[.deprecated-utilities-baseline.json](../../packages/ui/scripts/.deprecated-utilities-baseline.json)）或人工清单登记现状；清理过程中运行 `pnpm --filter brutx-ui-vue check:deprecated:update` 逐步收敛基线到零。

## C1 焦点体系残留 outline-none

- **范围**：11 处 `outline-none` 中删除 8 处（含 ring 遗物），豁免 3 处内层 input（input / number-input / TagsInput 的 `focus:outline-none`，容器 focus-within 为唯一指示）
- **依据**：裁决报告 §C1；机制与唯一例外见 [tailwind-v4-mechanisms.md](../guides/tailwind-v4-mechanisms.md) §1

## C2 手抄 shadow 值

- **范围**：`shadow-[Npx_..._rgba(...)]` 任意值字面量（Calendar / Counter / Counter test / Image(loading) / Loading / MessageContainer / Tour / loading.ts）
- **依据**：[.deprecated-utilities-baseline.json](../../packages/ui/scripts/.deprecated-utilities-baseline.json) 的 SHADOW_RGBA 项；迁移样板参照 Result / Image 已令牌化写法（`shadow-brutal*`）

## C3 硬编码颜色

- **范围**：Tailwind 默认色板与硬编码前景（`text-gray-500`、`bg-[#...]` 等）
- **依据**：裁决报告 §C3；规则见 [VISUAL_SYSTEM](../guides/VISUAL_SYSTEM.md) R6（`--brutal-*` 令牌与 `*-foreground` 家族）

## C4 border-3 双定义与细边框

- **范围**：`styles.css` 手写 `.border-3`（与 Tailwind 生成同值冗余）删除；细边框（如 MessageContainer `border-2`）迁移为粗边框
- **依据**：裁决报告 §C4；规则见 [VISUAL_SYSTEM](../guides/VISUAL_SYSTEM.md) R1

## C5 过渡声明与实际属性错配

- **范围**：code-block 复制按钮反馈失效 + 5 处死 `transition-all`
- **依据**：裁决报告 §C5；规则见 [COMPONENT_GUIDE](../guides/COMPONENT_GUIDE.md) r13（同一交互元素只声明一份 transition，twMerge 同组静默移除见 [tailwind-v4-mechanisms.md](../guides/tailwind-v4-mechanisms.md) §2）

## C7 command 按压反馈失效

- **范围**：command-variants.ts 的 `data-[highlighted]` 与 `brutalPress` 并存，按压反馈被 `data-*` 压过；需写 `data-*:active:...` 复合变体（特异度 `0,3,0`，含 `translate-x-0` 重置）
- **依据**：裁决报告 §C7；字节序机制见 [COMPONENT_GUIDE](../guides/COMPONENT_GUIDE.md)「共享交互变体机制契约」②

## 可选独立 PR：border-brutal 迁移 @utility

- **范围**：删除手写 `.border-3`，将 `.border-brutal` 移出 `@layer utilities` 转为顶层 `@utility`，复活 `hover:border-brutal` / `data-[highlighted]:border-brutal` 变体（command / menu 悬停边框）
- **注意**：行为变更，需视觉 QA，独立 PR 评审

## docs 侧 ring 残留

- **范围**：ThemePlayground.vue / visual/App.vue 等 docs 侧 `ring-*` 类（check:deprecated 只扫 `packages/ui/src`，不覆盖此面）
