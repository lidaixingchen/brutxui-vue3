## 详细改造实现

### 1. Doctor 命令目录遍历 I/O 并发优化

在 `packages/cli/src/commands/doctor.ts` 的 `findOrphanFiles` 函数中，将串行目录遍历与读取重构为 `Promise.all` 并发模式：

```typescript
const dirOrphanLists = await Promise.all(
    Array.from(directories).map(async (dir) => {
        if (!(await fs.pathExists(dir))) return [];
        const entries = await fs.readdir(dir, { withFileTypes: true });
        const list: string[] = [];
        for (const e of entries) {
            if (!e.isFile()) continue;
            const ext = path.extname(e.name).toLowerCase();
            if (!ORPHAN_EXTENSIONS.has(ext)) continue;
            const absPath = path.join(dir, e.name);
            if (!manifestAbsSet.has(absPath)) {
                list.push(path.relative(cwd, absPath).split(path.sep).join('/'));
            }
        }
        return list;
    })
);
orphans.push(...dirOrphanLists.flat());
```

### 2. Devtools 插件性能测量日志过载清理

1. 在 `DevtoolsPluginOptions` 与 `DEFAULT_OPTIONS` 中添加配置项：
   ```typescript
   export interface DevtoolsPluginOptions {
       // ...
       /** 是否将正常耗时的性能测量输出到控制台，默认 false */
       enablePerformanceLogging?: boolean
   }
   ```
2. 仅在 `duration > options.performanceThreshold` 时发出 `console.warn`；对于正常耗时，仅在 `options.enablePerformanceLogging === true` 时才输出 `console.log`，性能指标统一记录在 `performanceEntries` 列表中供 Devtools 面板及 API 读取。
3. 同步调整 `packages/ui/src/lib/devtools-plugin.test.ts` 中的测试用例与断言。
