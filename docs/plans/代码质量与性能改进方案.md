### 2. 子进程命令注入防护 (`packages/cli`)

在 `packages/cli/src/lib/run-process.ts` 中引入严格的 Shell 元字符防御：

```typescript
const SHELL_METACHARS_PATTERN = /[&|<>^%\r\n]/;

export function runProcess(command: string, args: string[], options: RunProcessOptions = {}): Promise<void> {
    const isWindows = process.platform === 'win32';
    const { cwd, stdio = 'inherit', onStdout, onStderr } = options;

    if (SHELL_METACHARS_PATTERN.test(command) || args.some((arg) => SHELL_METACHARS_PATTERN.test(arg))) {
        const offending = SHELL_METACHARS_PATTERN.test(command)
            ? `command "${command}"`
            : `arg "${args.find((a) => SHELL_METACHARS_PATTERN.test(a))}"`;
        return Promise.reject(new Error(`Command or arguments contain invalid shell metacharacters (${offending})`));
    }

    return new Promise<void>((resolve, reject) => {
        const child = spawn(command, args, {
            cwd,
            shell: isWindows,
            env: process.env,
            stdio: stdio === 'pipe' ? ['inherit', 'pipe', 'pipe'] : 'inherit',
        });
        // ...
    });
}
```

并在 `packages/cli/tests/security.test.ts` 中追加命令注入与管道拦截的单元测试。

### 3. Devtools 插件日志收敛与 Debug 机制 (`packages/ui`)

3. 保留受 `enablePerformanceLogging`、`enableEventLogging` 与 `performanceThreshold` 显式控制的日志输出；
4. 同步更新 `packages/ui/src/lib/devtools-plugin.test.ts`。

### 4. 事务并发安全加固与批量移除 N+1 消除 (`packages/cli`)

1. **`FileTransaction` 并发安全性**：
   - 解决并发快照时的资源竞争：使用 `tempDirPromise` 缓存异步创建的临时目录单例；
   - 采用递增原子计数器 `snapshotCounter` 生成唯一备份路径，杜绝哈希/索引碰撞；
   - 引入 `inFlightSnapshots` 映射避免同一文件并发多次快照。
2. **批量扫描与移除并发化**：
   - `findOrphanFilesInVfs` 改造为 `Promise.all(Array.from(directories).map(...))`；
   - `integrityOrphansRule.fix` 改造为 `Promise.all(orphans.map(...))`；
   - `remove-service.ts` 的 `executeRemoval` 改造为 `Promise.all` 并发移除组件目录与孤立文件。
