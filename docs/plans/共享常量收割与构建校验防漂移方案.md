## 一、 背景与第一性原理

### 1. 现状痛点与收割全景

在大型单体组件库的持续演进中，「局部绕过共享定义」、「构建脚本清单分叉」与「文档手写副本脱节」是系统性腐化和静默漂移的根源。根据审查报告与现行代码审查，库内需进一步收敛的关键防漂移点如下：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        手写副本与校验缺口全景                          │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 共享常量已有但局部绕过 (DRY 违背 & 原语红线):                       │
│    ├─ 浮动表面类串: Select / Cascader / Tour 需收敛至 brutalFloating   │
│    ├─ Tour 按钮原语: Tour.vue 内 3 处原生 <button> 需替换为 Button 组件 │
│    ├─ 分页尺寸默认值: Pagination.vue 手写 [10, 20, 50, 100]            │
│    ├─ Toast 默认时长: DEFAULT_TOAST_DURATION 常量定义需归位 defaults.ts│
│    └─ [已就绪] DatePicker 6 面板已全部复用 datePickerPanelVariants     │
│                                                                        │
│ 2. 构建与扫描脚本覆写清单分叉 (单一事实来源违背):                      │
│    ├─ build-registry.ts 本地残留 LIB_FILE_EXCLUDE = ['utils.ts']       │
│    ├─ generate-api-docs.ts 本地手写 CATEGORY_MAP (含陈旧键)            │
│    └─ generate-styles-tokens.ts 颜色组手写枚举需改为 CSS_VARS 动态派生 │
│                                                                        │
│ 3. 静态门禁与自动化修复增强:                                           │
│    ├─ [已就绪] audit-brutal-fallback.ts 已支持真实值比对与基线检测     │
│    └─ [待增强] audit-brutal-fallback.ts 补充 --fix 自动修复能力        │
│                                                                        │
│ 4. 文档手册手写色值与元数据漂移:                                       │
│    ├─ theme.md / en/theme.md 令牌表前景色错误 (手写 #FFF 未对齐 #000)  │
│    └─ 缺失 status-* / overlay-subtle / black / yellow 等新令牌         │
└────────────────────────────────────────────────────────────────────────┘
```

1. **共享常量与原语规范收敛**：
   - 浮动层容器（Select、Cascader、Tour）统一基于 [floating-content-variants.ts](../../packages/ui/src/lib/floating-content-variants.ts) 的 `brutalFloatingSurfaceClasses`；
   - `Tooltip` 保持反色表面 `inverseFloatingSurfaceClasses`（黑底白字），不与正色浮层混淆；
   - `Tour.vue` 内部存在原生 `<button>` 及手写内联样式，需按 [AGENTS.md](../../AGENTS.md) 组件库红线替换为 `Button` 组件；
   - `Pagination.vue` 未引用 `lib/defaults.ts` 中的 `DEFAULT_PAGE_SIZE_OPTIONS`。
2. **构建脚本单一来源收敛（SSOT）**：
   - `packages/registry/scripts/build-registry.ts` 残留本地 `LIB_FILE_EXCLUDE`，需完全使用从 `packages/ui/scripts/manifest-shared.ts` 导出的 `LIB_EXCLUDE`；
   - `packages/ui/scripts/generate-api-docs.ts` 本地手写 `CATEGORY_MAP`，需改为从 `packages/shared/src/component-metadata.ts` 读取权威分类并消费 shared 导出的分类中文字典；
   - `packages/ui/scripts/generate-styles-tokens.ts` 的 `THEME_GROUPS` 颜色组改为从 `CSS_VARS` 自动派生，避免新增颜色令牌时漏配 Tailwind `@theme` 工具类。
3. **门禁校验与自动化修复**：
   - `audit-brutal-fallback.ts` 已支持语义值一致性断言，需进一步补齐 `--fix` 自动纠偏能力，并在 CI 中确保 0 新增漂移。
4. **文档手写数据双语纠偏**：
   - `apps/docs/guide/theme.md` 与 `apps/docs/en/guide/theme.md` 中的设计令牌表格前景色全面纠偏（对齐 `BASE_THEME.light` 的高对比黑字标准），并补齐所有新增的运行时令牌。

## 二、 目标与重构原则

```text
┌────────────────────────────────────────────────────────────────────────┐
│                       防漂移四层防御矩阵                               │
├─────────────────┬──────────────────────────────────────────────────────┤
│ 1. 组件层 (UI)   │ 全面收敛至共享类串与 Button 原语，消除手写模板副本   │
├─────────────────┼──────────────────────────────────────────────────────┤
│ 2. 脚本层 (Build)│ build-registry 与 generate-api-docs 直连 shared 唯一源│
├─────────────────┼──────────────────────────────────────────────────────┤
│ 3. 门禁层 (Gate) │ audit-brutal-fallback 强化真实值比对与 --fix 修复能力 │
├─────────────────┼──────────────────────────────────────────────────────┤
│ 4. 文档层 (Docs) │ 双语纠偏 theme.md 令牌表，消除文档与源码事实分叉     │
└─────────────────┴──────────────────────────────────────────────────────┘
```

1. **零冗余原则（Single Point of Definition）**：
   - 浮动样式、分页尺寸、组件分类元数据一律使用单一权威定义，禁止在业务组件或脚本中内联手写副本。
2. **原语复用原则（Primitive Reuse）**：
   - 严格落实库内已有组件复用红线（`Button` 代替 `<button>`），严禁 native 元素替代与内联样式堆叠。
3. **真值校验与自动修复（Strict Value Verification & Auto-Fix）**：
   - 静态门禁断言真实 fallback 与 `BASE_THEME.light` 100% 一致，并提供 `--fix` 自动化纠偏工具。
4. **闭环防回潮（Automated Drift Prevention）**：
   - 所有单一定义均接入 CI 自动化检查与 prebuild 钩子，保证后续演进无法绕过。

## 三、 详细设计与重构方案

### 1. UI 共享常量与类串收割

#### 1.1 浮动表面统一复用 `brutalFloatingSurfaceClasses`
- **定义源**：[packages/ui/src/lib/floating-content-variants.ts](../../packages/ui/src/lib/floating-content-variants.ts)
- **收敛目标（正色浮层）**：
  - `SelectContent.vue` / `select-variants.ts`：将手写类替换为 `brutalFloatingSurfaceClasses`；
  - `Cascader.vue` / `cascader-variants.ts`：将手写类替换为 `brutalFloatingSurfaceClasses`；
  - `Tour.vue`：Popover 容器类收敛为 `brutalFloatingSurfaceClasses`。
- **反色浮层说明**：`TooltipContent.vue` / `tooltip-variants.ts` 保持消费 `inverseFloatingSurfaceClasses`（黑底白字），维持反色设计契约。

#### 1.2 Tour.vue 按钮原语规范化
- **文件**：[packages/ui/src/components/tour/Tour.vue](../../packages/ui/src/components/tour/Tour.vue)
- **改动**：
  - 引入库内 `Button` 组件：`import Button from '../button/Button.vue'`；
  - 将跳过、上一步、下一步/完成 3 处原生 `<button>` 替换为 `<Button>`，配置 `size="sm"` 与对应变体（`default` / `accent`），移除内联手写的 shadow/border/active 样式。

#### 1.3 分页与通知默认常量归位
- **分页默认配置**：[Pagination.vue](../../packages/ui/src/components/pagination/Pagination.vue) 的 `pageSizes` 默认值改为：
  ```typescript
  import { DEFAULT_PAGE_SIZE_OPTIONS } from '@/lib/defaults'
  // ...
  pageSizes: () => [...DEFAULT_PAGE_SIZE_OPTIONS],
  ```
- **Toast 时长常量**：
  - 将 `DEFAULT_TOAST_DURATION = 5000` 统一迁移至 [packages/ui/src/lib/defaults.ts](../../packages/ui/src/lib/defaults.ts) 并导出；
  - `useToast.ts` 从 `lib/defaults` 导入并 re-export 该常量以维持调用兼容；
  - `Toast.vue` 从 `lib/defaults` 统一引入。

#### 1.4 DatePicker 面板容器公共类（已就绪）
- `packages/ui/src/components/date-picker/date-picker-variants.ts` 中已固化 `datePickerPanelVariants`，且 6 个面板已全部接入，本次仅执行回归验证。

## 五、 验收标准

1. **常量与原语零重复**：
   - 全库弹出浮动表面样式 100% 消费 `brutalFloatingSurfaceClasses`（Tooltip 维持 `inverseFloatingSurfaceClasses`）；
   - `Tour.vue` 不再包含原生 `<button>` 手写样式；
   - 分页器与通知组件默认值均从 `defaults.ts` 统一导入。
2. **脚本单一事实来源**：
   - `build-registry.ts` 与 `generate-api-docs.ts` 不再保留任何本地手写的组件清单、排除集或分类字典；
   - Registry 构建产物与文档生成产物在 CI 中 100% 幂等。
3. **门禁拦截有效性**：
   - `pnpm --filter brutx-ui-vue prebuild:tokens` 与 `audit:fallback:check` 顺利通过；
   - 篡改任一组件中的 fallback 颜色值时，门禁精准报错并可由 `--fix` 自动修复。
4. **文档与代码一致性**：
   - VitePress 中英文文档中的设计令牌表格与 `packages/shared/src/design-tokens.ts` 逐项 100% 一致。
