# 图表数据契约与读数交互方案

## 一、目标与范围

为 [SketchyChart](../../../../packages/ui/src/components/sketchy-chart/SketchyChart.vue) 的 `line`、`bar`、`pie` 单序列图表建立可靠读数，保留手绘滤镜、排线纹理与主题能力。数据、图形、提示和等价表格使用一致语义，先完成数据正确性验收，再增加鼠标、键盘和触摸交互。

本方案独立于[组件视觉层级与交互动效改造方案](组件视觉层级与交互动效改造方案.md)交付与归档。本轮范围包括现有三类图形的数据处理与读数；大型数据可视化、通用图表引擎、图形入场播放另行设计。

## 二、数据与图形契约

### 数值语义

- 折线图和柱状图接受有限正数、负数及零，保留数值符号。Y 轴范围包含零与数据极值，柱体从零基线绘制到数值位置，折线面积以零基线闭合。
- 饼图接受有限的非负数，比例以完整有效输入的总和计算；零值保留在图例和数据表中，图中不生成可命中的扇区。
- 任一数据项为非有限数值，或饼图包含负值时，整张图进入明确的无效数据状态，不绘制部分图形或将错误数据转换为零。数据表保留原始标签，错误单元格使用本地化的无效值说明，数值格式化函数只接收有效有限值。
- 空数组显示空数据状态。全零折线和柱图显示零值数据及零基线；全零饼图显示“总量为零”的说明并保留图例和数据表，不表达占比。
- 单类别仅影响 X 轴布局，折线点在绘图区水平居中。Y 轴先取包含零和数据极值的上下界，仅当上下界相等时使用命名的退化范围常量；退化范围必须包含零。非零同值数据按实际范围绘制，例如 `[5, 5]` 使用包含 `[0, 5]` 的范围，单点 `[500]` 的范围必须包含其实际值。
- 折线面积表达相对零基线的大小，因此本轮折线与柱图均包含零。缺测值、可配置坐标域及跨更新身份保持属于后续公开契约扩展。

### 数值稳定性与格式化

- 有限输入的求和或差值仍可能溢出。饼图按最大正值缩放后累加并计算比例；折线与柱图先按最大绝对值缩放，再计算坐标域跨度。原始值始终保留，归一化只用于几何与比例计算。
- 坐标、刻度插值、弧度和路径参数必须保持有限，避免直接计算可能溢出的原始总和或 `max - min`。全零在归一化前单独分支处理；极端数量级差导致浮点下溢或像素不可辨识时，仍保留该项的原始读数、表格记录和键盘访问，不将其归类为原始零值。
- 数值刻度、提示、表格与可访问读数统一采用 `valueFormatter`。格式化函数须无副作用，在相同配置下对相同输入返回相同文本；调用次数不属于公开契约。默认格式根据当前语言环境生成，语言或 formatter 变化时刷新全部文本，不改变活动项身份。
- 刻度以有限的实际值格式化，保留其真实坐标；重复标签通过减少刻度密度处理，不修改原始数据或把取整后的数值用于坐标映射。
- 饼图百分比使用同一语言环境和命名精度常量，在默认提示、表格与可访问读数中保持一致。几何使用未格式化比例，各项显示值独立舍入，不强行调整某项凑成 `100%`；有舍入偏差时提供本地化说明。全零饼图比例显示“无法计算占比”，不显示为 `0%`。

### 类别完整性与展示容量

本轮三类图表均保留全部输入项，输入顺序作为类别顺序，不静默抽样或聚合。饼图使用完整总量；柱图保留每个类别；折线保留每个点与端点。标签排布可以减少可见刻度，但数据点、图例、数据表和键盘遍历不能因此缺失数据。

以现有抽样阈值附近以及超过阈值的数据建立回归，包括 31 个等值类别的饼图：每项占比应为完整总量的 `1 / 31`，格式化误差单独处理。较密数据通过容器布局和标签密度控制阅读节奏。数据完整性、图形可辨识性和指针可命中性分别验收；窄柱、小扇区和重合点可通过序号选择器及完整数据表读取，不承诺每个密集图形均有独立可辨识像素。基线记录代表性数据规模与渲染、遍历耗时，产品承诺的容量须有浏览器测量依据；若需要新增容量上限或降采样，先扩展公开数据契约再实施。

### 活动项生命周期

- 原始数组索引只表示当前数据快照中的位置，作为图形、图例、表格和插槽输出之间的映射。
- 数据数组替换、项目增删或重排、任一标签或数值变化、图表类型变化时，清除活动项与提示；相同长度或索引仍合法不能作为保留依据。
- 容器缩放只更新坐标和提示位置，保留当前活动项。关闭 `interactive`、空数据或进入无效状态时清除活动态。
- 组件内部维护活动状态。本轮不承诺跨数据更新保持选中身份。

## 三、公开接口与复用边界

| 接口 | 职责 |
| --- | --- |
| `interactive?: boolean` | 默认开启读数反馈；关闭时保留静态图形、图例、可访问描述和完整数据表入口 |
| `title?: string` | 业务标题，例如“月度销售额”；用于可见标题、图形名称、探索入口名称与表格标题 |
| `description?: string` | 业务方提供单位、统计口径与必要的趋势或关系说明，展示为关联说明文本 |
| `valueFormatter?: (value: number) => string` | 统一数值刻度、提示、表格与可访问读数；饼图比例另用统一百分比格式 |
| `tooltip` 插槽 | 提供 `index`、`label`、`value`、`formattedValue`；饼图另提供 `percentage`（比例数值，范围 `[0, 1]`）与 `formattedPercentage`，不可计算或其他图形时为 `undefined` |

Tooltip 插槽承载展示内容，禁止放置按钮、链接、输入框等可聚焦交互内容。需要操作的详情面板应使用具有独立焦点契约的弹层组件。默认文本使用 `useLocale()`，主题、表面、定位和格式化优先复用现有能力。内部 helper 保持私有；新增公开符号登记 `packages/ui/api-contract.ts`，通过生成流程维护入口和依赖闭包。

`title`、`description` 默认值为 `undefined`。未提供业务标题时使用本地化图表类型作为名称；文档和演示须为多图表页面提供可区分的业务标题。内部使用实例唯一 ID 关联可见标题、说明、图形和探索入口，不能依赖根容器属性透传自动命名内部控件。表格通过自身 `caption` 与列头保持独立语义，不将整个表格放入 `aria-describedby` 后当作长段文本读取。

数据校验与几何计算、格式化读数、输入状态转移分别组织为私有逻辑，图形、提示、图例与表格消费同一数据快照。探索控件优先复用库内 `Slider`；其焦点 thumb 的名称、说明和 `aria-valuetext` 绑定能力若不足，在所属组件内补齐并验证原有消费者。表格入口、展开面板及提示复用现有组件与浮层能力。

## 四、输入与提示生命周期

### 图形命中与活动标记

- 折线按最近横向数据位置选中；柱图以类别区域作为命中范围，零值及较短柱也能选中；饼图以扇区命中，零值通过图例或数据表读取。
- 活动标记以轮廓或标记配合颜色表达，并同步到图例与表格。单纯改变颜色不能作为唯一标识。
- SVG 与屏幕坐标换算考虑容器缩放，Tooltip 约束在可用边界内；验证小屏、页面滚动、父级裁切与 Dialog 内的层级。

### 鼠标与触摸

- 鼠标进入有效命中区时打开提示；移入 Tooltip 后保持当前项及提示，离开触发区域、移动通道和 Tooltip 后关闭，不设置自动消失计时。触发区域与 Tooltip 之间的间隙通过现有悬停保持机制或几何安全通道连接；通道内冻结活动项，避免前往提示途中切换到另一数据项。
- 提示出现时提供 Esc 关闭处理，包括鼠标打开而图表未获得焦点的情况。提示接入现有浮层的关闭顺序，同一按键只由当前最上层可关闭浮层处理；子级图表提示关闭后，该次事件不再关闭祖先 Dialog，下一次 Esc 按剩余浮层顺序处理。
- 多图表提示同时可见时，以现有浮层栈确定唯一 Esc 接收者，优先关闭当前最上层提示；其他图表不得同时消费该事件。若现有浮层机制不能承载此顺序，先补齐对应能力并通过原型验证，再集成图表。必要监听仅在提示可见时存在，关闭或卸载时移除，不为每张图表建立彼此独立的全局 Esc 处理器。
- Esc 关闭后，在指针重新进入触发区域、切换至另一数据项或显式键盘/触摸操作前保持关闭，避免微小移动立即重开。
- 触摸点击选择，再次点击同一项或点击外部关闭；移动和取消手势不产生点击选择，不阻止正常页面滚动。
- 键盘操作取得活动项控制权；随后明确的指针移动或触摸选择可切换控制权，静止指针不会覆盖键盘结果。

### 输入状态转移

活动项索引、提示可见性、输入来源（鼠标、键盘、触摸或空）及 Esc 抑制项分别维护。探索控件的当前位置可在提示关闭后保留，用于继续遍历；它不等于图形活动标记。数据快照变化时清空活动项与提示，并将探索位置重置到首项等待下一次显式操作。

| 事件与前提 | 状态与处理 |
| --- | --- |
| 探索控件通过键盘获得焦点 | 取得键盘控制权，从当前探索位置读取；新数据快照首次进入从首项开始 |
| 方向键、Home/End | 更新探索位置与活动项，打开提示；边界不循环，显式按键允许解除 Esc 抑制 |
| 键盘持有控制权时鼠标离开图形 | 保持键盘活动项与提示 |
| 鼠标产生明确位移并命中数据项 | 取得鼠标控制权并更新活动项；受 Esc 抑制的同项微小移动不重开 |
| 鼠标持有控制权时离开图形、移动通道与提示 | 关闭提示并清空活动标记 |
| 键盘持有控制权时 Tab 离开或控件失焦 | 关闭提示并清空活动标记，保留探索位置；不阻止 Tab，不以静止鼠标重新打开 |
| 触摸确认点击数据项 | 取得触摸控制权并打开提示；重复点击同项关闭，移动或取消手势不选择 |
| 触摸持有控制权时点击外部 | 关闭提示并清空活动标记；Tooltip 展示区域属于内部 |
| 当前浮层接收到 Esc | 关闭提示并清空活动标记，保留探索位置，记录被抑制项；同项重新进入、另一项命中或显式键盘/触摸操作解除抑制 |
| 数据失效、类型切换、关闭交互或卸载 | 清空活动状态、抑制状态及相关监听；数据变更后的鼠标静止不自动重开 |
| 缩放或滚动 | 更新几何与提示定位，不据此改变输入来源或选择另一项 |

指针接管依据实际位移，不以布局变化引起的 enter/leave 事件代替用户移动；触摸后的兼容鼠标事件不作为第二次操作。触摸手势容差使用命名常量，依据浏览器验证确定。

### 键盘与可访问读数

- 多项有效数据通过 SVG 外部可见的“浏览数据项”单 thumb 水平序号选择器探索，使用 Slider 语义。其选择值为数据序号，范围为首项到末项、步长为一个类别，业务数值保持只读。thumb 是唯一的探索 Tab 停靠点；每个 SVG 图形不增加 Tab 停靠点。
- 右/上方向键进入下一项，左/下方向键进入上一项，Home/End 到达首尾，到达边界不循环，Tab 正常离开。序号选择器包含所有类别，包括饼图中的零值；无扇区可标记时同步标记图例与已展开的表格行，提示锚定探索控件。控件的可见位置和标签应使序号选择含义清晰。
- 焦点 thumb 使用 `role="slider"`、合法的 `aria-valuemin/max/now`、本地化名称及关联操作说明。`aria-valuetext` 包含标签、格式化数值、当前位置和总项数，饼图追加占比或总量为零说明。键盘通过控件值变化播报，不再对同一读数叠加 live region 或重复的 Tooltip 描述。
- 探索位置仅由探索控件的操作更新；图形上的鼠标和触摸活动使用独立活动索引，不持续改写焦点 thumb 的 `aria-valuetext`。下一次键盘操作从保留的探索位置继续。读数区可随当前活动项更新，但不设置持续播报的 live region。
- SVG 保持 `role="img"`，通过标题与说明表达业务含义、图表类型及数据状态，不将其内部形状当作独立可访问控件。Tooltip 用于视觉读数，等价内容通过探索控件与完整表格提供。
- 单项有效数据使用具有明确名称的只读焦点区域展示唯一读数，获得键盘焦点时激活该项，不构造零跨度 Slider。空或无效状态使用同位置的只读焦点区域说明状态，方向键不消费；运行中状态切换时，仅当焦点原在探索入口内才将焦点转移至替代入口，避免焦点掉落或抢夺其他控件焦点。
- 使用库内 Button 与展开面板提供“查看数据表”入口，以 `aria-expanded` 和 `aria-controls` 关联语义表格。展开时焦点留在入口，表格位于其后供顺序读取，包含标题、列头、原始顺序、格式化读数和饼图占比；表格入口独立于探索入口，`interactive=false` 时依然可用，探索控件和图形读数提示则关闭。
- 默认描述包含图表类型和数据状态；业务方通过标题与描述补充单位、口径和必要的趋势关系，完整表格承载逐项读数。
- 使用统一焦点环，验证 forced-colors 和减少动态效果偏好；减少动态效果时标记与提示即时更新。

上述 DOM 与播报方案须在完整交互开发前，以最小原型在 Windows 浏览器配合 NVDA 下实测。记录浏览器及阅读器版本、浏览模式与焦点模式下的进入/遍历/退出、是否重复播报和表格读取结果；不能仅以合成键盘事件通过作为可访问性证明。序号选择器另须在触摸设备配合 VoiceOver 或 TalkBack 验证调节与退出，完整数据表始终提供独立读取路径。原型未通过时先修订控件语义和方案，再展开完整交互实现。

| 交互反馈 | 鼠标、键盘、触摸读取同一项得到一致标签与数值；悬停提示可移入、关闭并保持关闭 |
| 浏览器验收 | classic/pastel/mono 亮暗主题、窄屏、缩放、滚动、弹层内定位、阅读器及减少动态效果通过 |

- 两个 `Number.MAX_VALUE` 的饼图各占一半，正负最大有限值的坐标保持有限，以及极小有限值、数量级悬殊数据的完整读数。
- 格式化重复刻度、百分比舍入合计偏差、全零占比说明、语言及 formatter 切换后的读数一致性。
- 状态转移表中的控制权交接、失焦、边界遍历、Esc 抑制、触摸取消和兼容鼠标事件。

## 七、设计依据

- [W3C 悬停或聚焦内容要求](https://www.w3.org/WAI/WCAG21/Understanding/content-on-hover-or-focus.html)：提示可关闭、可悬停并保持至适当结束条件。
- [W3C 复杂图像说明](https://www.w3.org/WAI/tutorials/images/complex/)：为图表提供足以传达信息的等价描述与数据。
- [WAI-ARIA Tooltip 模式](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/)：参考信息展示与焦点处理；该模式仍标注为工作草案，整体交互以 WCAG 要求及实际辅助技术验证为准。
- [WAI-ARIA Slider 模式](https://www.w3.org/WAI/ARIA/apg/patterns/slider/)：序号选择器的角色、方向键、范围与可读值文本；须验证触摸辅助技术支持。
- [NVDA 用户指南](https://download.nvaccess.org/documentation/en/userGuide.html#BrowseMode)：浏览模式与焦点模式影响按键传递，探索控件须实测进入、操作和退出。
- [Reka UI Slider](https://reka-ui.com/docs/components/slider)：复用范围选择原语的键盘与焦点能力。
- [JavaScript 数值上限](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/MAX_VALUE)：有限输入的中间运算可能溢出，几何计算须保持稳定。
