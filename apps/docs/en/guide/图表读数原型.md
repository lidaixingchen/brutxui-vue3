# Chart Reading Prototype

This page uses the chart component to validate assistive technology and interaction. Record automated and screen reader results separately. The sample readings are in Chinese.

## Test Steps

1. Enable NVDA and record its version and your browser version. Read both chart titles, descriptions, and table disclosure buttons in browse mode.
2. Tab to the first data-item slider. Check its name, instructions, category, value, position, and total count. Record whether focus mode starts automatically or requires a manual switch.
3. Use the arrow keys, Home, and End. Verify every category is reachable, boundaries do not wrap, signed and zero values are readable, and each change is announced once. Escape closes the tooltip; another arrow key resumes reading; Tab leaves normally.
4. Expand the complete data table. Check that focus stays on the disclosure button, the expanded state is announced, and all rows can be read with their column headers.
5. Hover the chart's data area and move to its tooltip. The tooltip should remain available across the gap. Escape dismisses it; small pointer movements within the same item should not reopen it; leaving and re-entering permits reopening.
6. Open the dialog and focus its slider. The first Escape closes only the tooltip. The second closes the dialog and restores focus to the opening button.
7. On a real touch device, enable VoiceOver or TalkBack, adjust the slider to both endpoints, leave it, and read the table. Record device, OS, reader, and browser versions.

## Feedback

Report environment versions, each step's outcome, actual announcements, focus location, and whether navigation remains possible. Mark unavailable checks as untested rather than passed.
