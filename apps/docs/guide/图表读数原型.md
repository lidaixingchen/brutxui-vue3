# 图表读数原型

本页使用正式图表组件进行辅助技术与交互验收。自动化结果与实际阅读器结果分别记录。

## 操作步骤

1. 开启 NVDA，记录 NVDA 和浏览器版本。从浏览模式阅读两个图表的标题、说明及数据表入口。
2. 按 Tab 进入“月度净收入：浏览数据项”，确认名称、操作说明、标签、数值与“第几项／共几项”可读。记录是否自动进入焦点模式；如果需要手动切换，记录操作。
3. 按右、左、Home、End，检查三项逐一可达、边界不循环、负值与零值可读，每次变化不重复播报。按 Esc 关闭提示，再按方向键可继续读取；Tab 能正常离开。
4. 激活“查看数据表”，确认焦点留在入口，展开状态可读，能够按表格列头和行读取所有数据。
5. 将鼠标移入图形的数据区域，再移入提示，检查间隙内提示不消失。按 Esc，同一项内轻微移动鼠标不应重开，离开后重新进入允许打开。
6. 打开弹窗，把焦点移到其中的序号控件。第一次 Esc 只关闭提示，第二次 Esc 关闭弹窗，焦点回到打开按钮。
7. 在真实触摸设备上启用 VoiceOver 或 TalkBack，找到序号选择器，调节至首尾，离开控件并读取完整表格。记录设备、系统、阅读器与浏览器版本。

## 反馈格式

请反馈环境版本、各步骤通过或失败、实际播报内容、焦点去向及能否继续操作。无法执行的步骤记为“未测”，不记为通过。
